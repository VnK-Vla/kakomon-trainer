## 最初に覚える10行

1. 磁気共鳴画像（MRI）は主に水素原子核の**共鳴後の信号**を、コンピュータ断層撮影（CT）はX線の**線減弱係数**を画像にする。
2. スピンエコー（SE）系MRIのT1強調は原則「短い繰り返し時間（TR）・短いエコー時間（TE）」、T2強調は「長いTR・長いTE」、プロトン密度（PD）強調は「長いTR・短いTE」。グラジエントエコー（GRE）ではフリップ角と定常状態、反転回復法（IR）では反転時間（TI）も重要。
3. SEは180°パルスで静的な磁場不均一による位相ずれを再収束し**T2**をみる。GREは180°パルスを使わず、**T2\***と磁化率に敏感。
4. k空間の中央は信号とコントラスト、周辺は輪郭と細部に強く寄与する。どこから収集するかは撮像法によって異なる。
5. 拡散強調像（DWI）が高信号というだけで拡散制限と断定しない。**DWI高信号＋見かけの拡散係数（ADC）低値**を確認する。
6. MRIでは、位相方向に動きのゴーストと折り返し、周波数方向に化学シフト・アーチファクト1型が出やすい。
7. ハンスフィールド単位（HU）で表すCT値は `HU = 1000 × (μ − μ水) / μ水`。水0 HU、空気−1000 HUが基準。
8. CTの量子雑音は概ね `1 / √mAs`、線量は概ね管電流時間積（mAs）に比例する。線量を半分にしても雑音は2倍ではなく約√2倍。
9. CTのz軸分解能は再構成スライス厚だけでなく、検出器幅・ピッチ・補間・再構成法に依存する。
10. 容積CT線量指数（CTDIvol）は装置出力の指標で、線量長積（DLP）は `DLP = CTDIvol × 撮影長`。どちらも個々の患者の吸収線量そのものではない。

# 第I部　MRI

# 1. MRIは何を画像にしているか

## 1-1. 信号が生まれるまで

> **まずこの理解**：体内の水素原子核を「向きのそろいにくい小さな磁石」、静磁場を「小さな磁石をわずかに整列させる力」、高周波パルスを「そろった磁化を横へ倒す合図」と考えるとよい。これは比喩であり、正確には、水素原子核の磁気モーメントが静磁場中でわずかな分布差を生じ、集団としての磁化が高周波磁場に共鳴して向きを変える現象である。

**体内で何が起こるか**：MRIでは、体内に多い水素原子核（プロトン）を主な信号源とする。個々の水素原子核は磁気モーメントをもち、静磁場 `B0` に入ると、静磁場と平行な状態が反平行な状態よりわずかに多くなる。この小さな差が集まって、静磁場方向の縦磁化 `Mz` が生じる。同時に、水素原子核は `B0` の周りを歳差運動する。

**装置が何をするか**：装置は、水素原子核の歳差運動と同じラーモア周波数の高周波（RF）磁場 `B1` を加え、磁化を傾けて横磁化 `Mxy` を作る。RFを止めると、縦磁化は回復し、横磁化は位相がばらついて減衰する。受信コイルが横磁化の時間変化を電気信号として検出し、傾斜磁場が位置情報を付ける。

**画像にどう表れるか**：組織ごとの水素原子核の量、縦磁化の回復速度、横磁化の減衰速度の違いが信号差となる。受信した信号をk空間に並べ、フーリエ変換すると画像になる。

```
B0をかける
   ↓  水素原子核の分布にわずかな偏り → 縦磁化 Mz
ラーモア周波数のRFを加える
   ↓  共鳴して磁化が傾く → 横磁化 Mxyが生じる
RFを止める
   ├─ 縦方向へ戻る：T1緩和
   └─ 横方向の位相が崩れる：T2/T2*緩和
受信コイルが時間変化する横磁化を検出
   ↓
傾斜磁場で位置情報を付与 → k空間 → フーリエ変換 → 画像
```

ラーモア周波数は

`f0 = (γrad / 2π) B0`

である。ここで `γrad` は角磁気回転比（単位 rad/s/T）である。水素では `γrad / 2π ≈ 42.58 MHz/T` なので、1.5 Tでは約63.9 MHz、3 Tでは約127.7 MHzとなる。

RF磁場 `B1` によるフリップ角は、磁場の強さと加える時間の積で決まる。理想化すると、角磁気回転比 `γrad` を用いて

`α = γrad ∫ B1(t) dt = 2π (γrad/2π) ∫ B1(t) dt`

と表せる。平衡磁化を角度αだけ倒すと、直後の成分は概念的に `Mz = M0 cos α`、`Mxy = M0 sin α` である。

**試験の要点**：静磁場が強いほど共鳴周波数は高い。RFは信号そのものを直接作るのではなく、縦磁化を傾けて受信可能な横磁化を作る。画像の明暗は「水素があるか」だけでなく、その後のT1回復とT2/T2\*減衰をいつ測るかで変わる。

## 1-2. T1・T2・T2\*を一本の物語にする

| 現象 | 何が回復／減衰するか | 理想式 | 主に反映する撮像 |
|---|---|---|---|
| T1緩和（スピン・格子緩和） | 縦磁化Mzの回復 | `Mz(t)=M0[1−exp(−t/T1)]`（90°後） | T1強調、スポイルドGRE、IR |
| T2緩和（スピン・スピン緩和） | スピン間相互作用による横磁化の減衰 | `Mxy(t)=Mxy(0)exp(−t/T2)` | SE/FSEのT2強調 |
| T2\*減衰 | T2＋静的磁場不均一・磁化率差 | `1/T2* = 1/T2 + 1/T2′` | GRE、GRE-EPI、SWI、BOLD |

通常は `T2 ≤ T1`、かつ `T2* ≤ T2`。180°再収束パルスは、時間的にほぼ一定な周波数ずれを再収束できるため、SEではT2\*ではなくT2に近いエコーが得られる。ただし、真のスピン・スピン相互作用や拡散による不可逆な位相分散は元に戻せない。

### T1・T2を直感で覚える

- T1：**縦磁化の充電速度**にたとえられる。正確には、縦磁化が平衡状態へ回復する時定数であり、短い組織ほど次のRFまでに早く回復する。
- T2：**横磁化の足並みがそろっていられる時間**にたとえられる。正確には、スピン・スピン相互作用により横磁化が減衰する時定数であり、長い組織ほどTEを待っても信号が残る。
- T2\*：T2による不可逆な減衰に、装置や組織境界の静的な磁場むらによる可逆的な位相ずれが加わった見かけの減衰である。

## 1-3. プロトン密度だけでは信号は決まらない

信号強度は、プロトン密度、T1、T2/T2\*だけでなく、撮像法、TR、TE、TI、フリップ角、コイル感度、ボクセル、血流、拡散、磁化率、造影剤、再構成などの積み重ねで決まる。したがって「この物質は必ず高信号」と暗記せず、**どの撮像法で、どの条件か**を必ず付ける。

代表的な傾向：

- 脂肪：短いT1でT1高信号。脂肪抑制や同位相・逆位相画像で同定する。
- 自由水・浮腫：長いT2でT2高信号。単純液体はFLAIRで抑制される。
- 急性〜亜急性血腫：時期により酸素化ヘモグロビン、脱酸素化ヘモグロビン、メトヘモグロビン、ヘモジデリンへ変化し、T1・T2・磁化率が変わる。
- 鉄・ヘモジデリン・空気・金属：局所磁場を乱し、特にT2\*/GRE/SWIで信号低下とブルーミングを生じる。
- 石灰化：多くは低信号だがMRI単独で鉄との区別が難しいことがあり、CTが有用。
- 高蛋白・粘稠液：蛋白濃度や水分量によりT1短縮やT2短縮が起こり、単純な「液体＝T2高」から外れる。
- コラーゲンの多い線維性組織：動きやすい水素原子核が少なく、しばしばT2低信号。
- マジックアングル：腱などの規則的なコラーゲン線維がB0に対して約55°になると、短TE画像で偽高信号を示す。長TEのT2強調で軽減する。

### 血腫の時相を最小限で整理

| 概略時相 | 主成分 | 典型的T1 | 典型的T2/T2\* | 手がかり |
|---|---|---|---|---|
| 超急性期 | 細胞内酸素化ヘモグロビン | 等〜低 | T2高 | CTで急性血腫、MRIでは時相依存 |
| 急性期 | 細胞内脱酸素化ヘモグロビン | 等〜低 | T2/T2\*低 | 磁化率効果が出る |
| 亜急性期早期 | 細胞内メトヘモグロビン | 高 | T2低 | T1高＋T2低 |
| 亜急性期後期 | 細胞外メトヘモグロビン | 高 | T2高 | T1/T2とも高くなりやすい |
| 慢性期の辺縁 | ヘモジデリン／フェリチン | 低〜等 | T2/T2\*低 | GRE/SWIで辺縁のブルーミング |

これは教育的な概略で、磁場強度、撮像法、部位、酸素化、再出血により所見は混在する。血腫の時相を1枚の画像だけで断定しない。

# 2. 位置情報とk空間

## 2-1. 3本の傾斜磁場の役割

傾斜磁場コイルは、位置に比例して磁場の強さを少しずつ変える。x・y・zの各軸は固定の役割をもつのではなく、選んだ断面に応じて次の3役へ割り当てられる。

1. **スライス選択**：RF照射中に傾斜磁場を加え、特定の周波数帯に対応する位置だけを励起する。
2. **位相エンコード**：短時間だけ傾斜磁場を加え、位置ごとに異なる位相を残す。強さを変えながら撮像を繰り返す。
3. **周波数エンコード（読み出し）**：信号の読み出し中に傾斜磁場を加え、位置を周波数差に変える。

スライス厚は、RFパルスが励起する周波数帯域を狭くするほど、またスライス選択傾斜磁場を強くするほど薄くなる。概念式は

`Δz = BW_RF / [(γrad/2π) Gslice]`

である。`BW_RF` はRFパルスの周波数帯域、`Gslice` はスライス選択傾斜磁場の強さを表す。傾斜磁場をどれだけ速く立ち上げられるかをスルーレートという。高い傾斜磁場性能は薄いスライス、短いTE、EPI、DWIに有利だが、騒音と末梢神経刺激が制約になる。

### 3種類のコイルを混同しない

- **主磁石**：静磁場B0を作る。通常の超電導MRIでは常時磁場が存在する。
- **傾斜磁場コイル**：B0へ位置依存の小さな変化を重ね、スライス選択・位相エンコード・周波数エンコードを行う。急速な切替えが騒音と末梢神経刺激を生む。
- **RFコイル**：B1の送信、信号の受信、または両方を担う。送信専用・受信専用・送受信兼用があり、全身コイルで送信し、局所のフェーズドアレイコイルで受信する構成も一般的である。表面コイルは近くで高いSNRを得やすいが感度が不均一である。フェーズドアレイコイルは複数の小コイルを組み合わせ、広い撮像範囲と並列撮像を両立する。受信コイルを対象へ近づけ、コイル内で対象が占める割合を高めるとSNRに有利である。

## 2-2. k空間は「画像の設計図」

> **まずこの理解**：k空間を「画像の設計図」と考えると、中央には全体の明暗やコントラスト、周辺には細かな輪郭が多く記録される。ただし、中央が画像の中央、周辺が画像の端に対応するわけではない。正確には、k空間は信号の空間周波数と位相を並べる生データ領域であり、1点ずつがフーリエ変換後の画像全体へ寄与する。

**体内で何が起こるか**：RFで生じた横磁化は、組織の位置に応じて異なる位相と周波数をもつようになる。

**装置が何をするか**：傾斜磁場の強さと加える時刻を変え、位相エンコード方向と読み出し方向の信号を順番に収集してk空間へ配置する。

**画像にどう表れるか**：k空間中央の欠損や不整合は画像全体の信号とコントラストに強く影響し、周辺の欠損は輪郭をぼかす。収集後にフーリエ変換して位置ごとの画像へ戻す。

```
             ky（位相方向）
                 ↑
  周辺：高空間周波数 │ 周辺：輪郭・細部
  ─────────────────────→ kx（読み出し方向）
                 ●
       中央：低空間周波数・信号・コントラスト

中央だけ → ぼやけるが大まかなコントラストは残る
周辺不足 → 輪郭が鈍る
中央の動き・不整合 → 画像全体に強いアーチファクト
```

「k空間は中央から収集する」とは限らない。直線順、中心優先、中心後回し、放射状などの収集順があり、造影MRAや動態撮像では、中央をいつ取得するかが造影のタイミングを左右する。

部分フーリエ法は、理想的な実数画像のフーリエデータがもつ共役対称性と位相推定を利用し、k空間の半分より多い部分を収集して残りを推定する。時間を短縮できるが、SNR低下、位相誤差、再構成アーチファクトが代価となる。単純な「鏡写し」や「SNRが必ず1/2」ではない。

キーホール法／ビューシェアリングは、動態撮像でコントラストを担うk空間中央を頻回に更新し、周辺データを前後の時相から流用する。見かけの時間分解能は上がるが、急速な変化の時間方向のぼけや、古い輪郭情報が残る。

2次元（2D）撮像では通常、1回の読み出しでkx方向の1行を収集し、位相エンコードを変えてky方向を埋める。3次元（3D）撮像ではスラブを励起し、さらにkz方向にも位相エンコードを行う。

**試験の要点**：k空間中央は主に信号とコントラスト、周辺は主に輪郭と細部に寄与する。どの領域も画像全体へ寄与し、収集順は一定ではない。位相エンコード回数を減らせば時間は短くなるが、分解能低下や折り返しなどの代価が生じる。

## 2-3. 撮像視野（FOV）・マトリックス・ボクセル

`画素寸法 = FOV / マトリックス`

`ボクセル体積 = Δx × Δy × スライス厚`

同じFOVならマトリックスを増やすと画素は小さくなり、公称空間分解能は上がるが、1ボクセルの信号が減ってSNRは下がる。位相方向のマトリックスを増やすと、通常は撮像時間も延びる。読み出し方向のマトリックスを増やす場合は、同じ標本化時間なら受信帯域幅との関係も変わるため、単純な暗記にしない。

FOVとk空間の標本化間隔の関係は、概念的に `FOV = 1/Δk` であり、分解能は最大空間周波数 `kmax` で決まる。FOVを小さくしすぎて被写体が範囲外へ出ると、折り返しが起きる。

## 2-4. 撮像時間

2D FSEの概算は

`TA ≈ TR × Ny × NEX / (ETL × R) × 部分フーリエ実収集率`

3Dでは、さらにスライスエンコード数 `Nz` が関係する。ここで `Ny` は位相エンコード数、`NEX` は加算回数、`ETL` はエコートレイン長、`R` は並列撮像の加速係数、部分フーリエ実収集率は6/8のように1未満で表す。実機では定常状態を作るための準備パルス、呼吸・心電図（ECG）同期、同時多断面励起（SMS）、ビューシェアリングなどが加わるため、この式は条件を比べるための概算と考える。

### 時間を短くする主な方法

- 位相方向のマトリックスやNEXを減らす。
- ETL（ターボ係数）を増やす。
- 並列撮像、部分フーリエ法、圧縮センシングを使う。
- 1回励起法、EPI、放射状収集など、目的に合う読み出し法へ変える。
- TRを短くする。ただしコントラスト、比吸収率（SAR）、定常状態も変わる。

時間短縮には、SNR低下、ぼけ、折り返し、アーチファクト、コントラスト変化などの代価がある。

# 3. 基本撮像法を系統立てる

## 3-1. SEと高速／ターボスピンエコー（FSE/TSE）

> **まずこの理解**：横磁化の足並みが磁場むらで崩れたとき、180°パルスは「先頭と最後尾を入れ替え、再び集合させる折り返し点」にたとえられる。ただし、この比喩で戻せるのは時間的にほぼ一定な周波数差による位相ずれだけである。スピン同士の相互作用による真のT2減衰は戻せない。

**体内で何が起こるか**：90°パルスで横磁化が生じた後、スピンの位相はT2緩和と静的な磁場むらの両方でばらつく。

**装置が何をするか**：SEはTEの中間で180°パルスを1回加え、静的な磁場むらによる位相ずれを再収束させる。FSE/TSEは1回の励起後に180°系パルスを繰り返し、複数のエコーでk空間の複数行を収集する。

**画像にどう表れるか**：SE/FSEでは静的な磁場むらによる位相ずれが再収束され、横磁化の減衰はT2に従う。ただし、T1・プロトン密度・T2のどのコントラストを強調するかはTRとTEで決まる。FSE/TSEは速いが、長いエコートレインではエコーごとの信号差がk空間に混ざり、T2ぼけや混合コントラストを生じる。

```
SE：   90° ───── 180° ───── エコー
                 TE/2      TE/2

FSE：  90° ─ 180°-E1 ─ 180°-E2 ─ 180°-E3 …
                  各エコーでk空間の別の行を収集
                  中央の行を埋めるエコーのTE＝実効TE
```

SE信号の簡略式は

`S_SE ∝ ρ [1 − exp(−TR/T1)] exp(−TE/T2)`

- **短TR**：T1回復差が残る → T1強調が強い。
- **長TR**：T1差が減る。
- **長TE**：T2減衰差が広がる → T2強調が強いが全体信号は低下。
- **短TE**：T2差を抑える。

| 画像 | TR | TE | 主なコントラスト |
|---|---|---|---|
| T1強調SE | 短い | 短い | T1差 |
| T2強調SE/FSE | 長い | 長い | T2差 |
| PD強調 | 長い | 短い | プロトン密度差 |

FSE/TSEは1回の励起後に複数のエコーを得るため高速だが、長いETLではT2減衰によりk空間の行ごとに信号が変わり、ぼけや混合コントラストが生じる。180°系パルスが多いほど、RFエネルギー付与による比吸収率（SAR）と磁化移動（MT）効果が増え得る。通常のSEより磁化率アーチファクトが弱く、J結合効果の低減により脂肪が比較的高信号になりやすいことも重要である。

1回励起FSE（HASTE/SSFSE）は、1回の励起で画像の大部分を収集するため動きに強く、MRCP、MR尿路撮影（MRU）、腹部T2強調像に有用である。ただし、T2ぼけ、分解能低下、信号低下などに注意する。

**試験の要点**：SEの180°パルスが再収束できるのは静的な磁場不均一による可逆的な位相ずれであり、真のT2減衰ではない。FSEの実効TEは、k空間中央を収集したエコーの時刻で決まる。ETLを増やすと撮像は速くなるが、T2ぼけとSARに注意する。

## 3-2. GRE系

> **まずこの理解**：GREは「180°パルスで足並みをそろえ直さず、傾斜磁場を反転してエコーを作る速い方法」である。正確には、傾斜磁場によって生じた位相ずれは傾斜磁場の反転で再収束できるが、静的なB0不均一による位相ずれは補正できない。このため信号はT2ではなくT2\*減衰の影響を受ける。

**体内で何が起こるか**：励起後の横磁化は、T2緩和に加えて静的な磁場むらや磁化率差でも位相がばらつく。

**装置が何をするか**：GREは180°再収束パルスを使わず、傾斜磁場を反転してエコーを作る。短いTR・TEと小さなフリップ角を使いやすい。

**画像にどう表れるか**：高速なT1強調3D撮像や動態造影に向く一方、T2\*と磁化率に敏感で、出血・鉄・空気・金属を強く描出し、歪みや信号欠損も生じやすい。

| GRE系 | 横磁化の扱い | 主なコントラスト・用途 | 弱点 |
|---|---|---|---|
| スポイルドGRE | 残留横磁化をRFまたは傾斜磁場で消す | T1強調、動態造影、3D撮像 | B1不均一、条件に依存するT1コントラスト |
| コヒーレントGRE | 残留横磁化と刺激エコーを利用 | T2/T2\*混合、関節など | 血流と定常状態の複雑さ |
| 平衡型定常自由歳差運動（bSSFP） | 各TRで全傾斜磁場の積分値を均衡 | おおむねT2/T1比、血液・液体高信号、心臓動画 | 共鳴周波数ずれによる帯状信号欠損、SAR |
| GRE-EPI | 長い傾斜磁場エコートレイン | BOLD、超高速撮像 | 磁化率歪み、N/2ゴースト |

スポイルドGREの定常状態信号は

`S ∝ ρ sinα (1−E1) / (1−E1 cosα) × exp(−TE/T2*)`

`E1 = exp(−TR/T1)` である。一定のTRで信号を最大にするエルンスト角は

`cos αE = exp(−TR/T1)`

である。実際の「T1強調が最大」と「SNRが最大」は同じ意味ではなく、目的組織、コントラスト、SARを考えて設定する。

**試験の要点**：SEは180°パルスで静的な磁場むらを補正してT2を反映し、GREは補正しないためT2\*と磁化率に敏感である。GREのコントラストはTR・TEだけでなく、フリップ角と定常状態にも左右される。

## 3-3. IR：TIで特定組織を消す

理想的な180°反転パルス後の縦磁化は

`Mz(TI) = M0 [1 − 2 exp(−TI/T1)]`

であり、信号がゼロになる時点は `TI ≈ T1 ln 2` である。実際にはTR、フリップ角、読み出し法で変わる。

| 撮像法 | 信号をゼロにするもの | 主用途 | 重要な注意 |
|---|---|---|---|
| STIR | 短T1の脂肪 | 全身・骨髄・B0不均一部の脂肪抑制 | T1依存で非特異的。造影でT1短縮した組織も抑え得るため、原則としてGd造影後の病変評価に不適 |
| 液体減弱反転回復法（FLAIR） | 長T1の脳脊髄液（CSF） | 脳浮腫、脱髄、くも膜下腔病変 | 不完全抑制、血流、酸素・蛋白・造影によるCSF高信号に注意 |
| LGE用IR／位相感応型反転回復法（PSIR） | 正常心筋など | 梗塞・線維化 | TI設定と撮像時期が重要。PSIRは信号ゼロ点のずれに比較的強い |

脂肪のT1はCSFよりはるかに短いため、通常は **STIRのTI < FLAIRのTI** となる。固定TI値は磁場強度、TR、反転効率で変わる。

## 3-4. EPI、並列撮像、3D撮像

EPIは位相エンコード用の小さな傾斜磁場と読み出し傾斜磁場の反転を繰り返し、1回または少数回の励起でk空間をジグザグに読む。DWIでは主にSE-EPIが使われ、中心エコーはT2寄りとなる。DSCやBOLDでは主にGRE-EPIが使われ、T2\*を反映する。DWIには非EPIのTSE法や読み出し分割法もあり、灌流撮像にはDCEやASLもある。エコー間隔が長いと、共鳴周波数ずれによる位相方向の歪みが増える。

並列撮像は複数コイルの感度分布を位置情報として利用し、位相エンコードを間引く。感度符号化法（SENSE）は主に画像空間で、自己校正型k空間法（GRAPPA）は主にk空間で不足データを補う代表法である。加速係数をRとすると

`SNR_R ≈ SNR_0 / (g √R)`

となる。ここで `SNR_0` は未加速時のSNRである。幾何係数（g因子）は、コイルの配置に由来する雑音増幅を表す。並列撮像は撮像時間だけでなく、EPIのエコートレインと歪み、FSEのSARも減らせる。

3D撮像は、薄い連続スライス、等方性ボクセル、多断面再構成、高いSNR効率に有利だが、撮像時間、広範囲の体動、スラブ内コントラスト、SARに注意する。2D撮像は各スライスを独立に励起でき、体動の影響を局所化しやすいが、スライス間隔、交差干渉、厚いスライスになりやすい点に注意する。

# 4. 脂肪、水、血液を分ける

## 4-1. 脂肪抑制法の使い分け

| 方法 | 原理 | 長所 | 弱点・注意点 |
|---|---|---|---|
| STIR | 脂肪の短いT1に合わせ、IRで脂肪信号をゼロにする | B0不均一に比較的強く、広範囲・金属近傍で使いやすい | 脂肪特異的でない、SNR低下、Gd造影後の増強評価に不適 |
| 化学シフト選択飽和法（CHESS）／周波数選択的脂肪抑制（FS） | 水と脂肪の共鳴周波数差を使い、脂肪だけを飽和させる | 脂肪特異的で、造影T1強調像に使用できる | B0/B1不均一、金属、大きなFOVで抑制むら |
| 周波数選択的断熱反転回復法（SPAIR） | 脂肪を周波数選択的な断熱反転パルスで反転し、TI後に信号をゼロにする | 脂肪特異的で、SPIRよりB1不均一に比較的強い | B0、TI、RF負荷、撮像時間に依存 |
| 周波数選択的反転回復法（SPIR） | 脂肪を周波数選択的な非断熱反転パルスで反転し、TI後に信号をゼロにする | 脂肪特異的 | B0/B1、反転角、TIに依存 |
| ディクソン法 | 水と脂肪の位相差から水画像と脂肪画像を再構成 | 均一性が高く、同位相・逆位相画像も得られる | 体動、磁場分布推定、分離失敗、脂肪の多峰性モデルに依存 |
| 水選択励起法 | 二項RFパルスなどで水を選択的に励起 | 脂肪抑制ができ、比較的高速 | B0/B1と撮像法に制約 |

水と脂肪の化学シフト差は約3.5 ppmである。周波数差は磁場強度に比例し、約224 Hz（1.5 T）、447 Hz（3 T）となる。

### 化学シフト・アーチファクトの2種類

1. **1型**：水と脂肪が読み出し方向の異なる位置へずれる。画素単位のずれは `Δf /（1画素当たりのBW）` である。高磁場・狭い帯域幅で増悪し、広いBW・脂肪抑制で軽減する。読み出し方向を変えてもずれの量は減らないが、重要部位からアーチファクトを退避できる。
2. **2型**：同一ボクセル内に水と脂肪があると、逆位相で両者が相殺され、境界に黒い縁を作るインディアインク徴候や実質の信号低下となる。脂肪肝や副腎腺腫などの微量脂肪検出に使う。

目安として、1.5 Tでは逆位相／同位相が約2.2/4.4 ms、3 Tでは約1.1/2.2 msとなるが、脂肪スペクトルの多峰性や装置実装により調整される。**逆位相での信号低下には、水と脂肪が同一ボクセル内に共存する必要がある**。

## 4-2. 磁化率と血液産物

局所の磁化率差はB0を乱し、位相分散、信号欠損、形状の歪みを生む。GRE、長いTE、高磁場、EPIで強くなる。SE/FSE、短いTE、小さいボクセル、適切な静磁場均一化（シミング）は、ボクセル内位相分散とブルーミングを減らす。広いBWと短いエコー間隔は、主に幾何学的な歪みと位置ずれを減らす。ただし、BWを広げるだけでは失われた信号を再収束できない。

| 磁性 | B0への反応 | 代表 | 画像・安全との関係 |
|---|---|---|---|
| 反磁性 | ごく弱く反発 | 多くの生体組織、水 | 磁化率差は小さい |
| 常磁性 | 弱く引かれる | Gd、脱酸素化ヘモグロビンなど | 局所のT1/T2\*へ影響 |
| 超常磁性 | 強い局所磁化を示すが残留磁化は小さい | SPIO、鉄粒子 | 強いT2/T2\*短縮とブルーミング |
| 強磁性 | 強く磁化され、磁場を除いても磁化が残り得る | 一部の鉄系物体 | 吸着・飛来、回転力、強いアーチファクト。材質同定が必要 |

- T2\* GRE：微小出血、ヘモジデリン、鉄沈着、静脈を検出する。
- SWI：強度情報と位相情報を組み合わせ、磁化率差を強調する。ブルーミングの大きさは病変の実寸ではない。
- 磁化率定量画像（QSM）：位相から磁化率を定量推定するが、再構成法、撮像方向、背景磁場除去の影響を受ける。
- 石灰化と血液産物はともに低信号になり得る。位相画像やQSMが参考になるが、CTで確認するのが確実な場面が多い。

## 4-3. 造影剤が「光る」のではない

Gdキレートは、近傍にある水の水素原子核の緩和を促進する。

`1/T1 = 1/T1,0 + r1 [C]`

`1/T2 = 1/T2,0 + r2 [C]`

ここで `[C]` は造影剤濃度、`r1` と `r2` はそれぞれT1・T2緩和能を表す。

通常濃度では、T1短縮をT1強調像の高信号として捉える。T1強調DCEでは初回通過を信号増強として測り、T2/T2\*強調DSCでは局所濃度上昇を信号低下として測る。非常に高濃度ではT2/T2\*短縮が優位になり得る。したがって、造影剤そのものが「光る」のではなく、濃度、撮像法、撮像時期が重要である。

- 動的造影MRI（DCE）：T1強調像で時間的な増強を評価する。得られる変化には血流、血管透過性、細胞外腔などが混在する。
- 動的磁化率コントラスト灌流（DSC）：主に脳で、造影剤の初回通過時に生じるT2\*信号低下を測る。`ΔR2*(t)=−ln[S(t)/S0]/TE` で信号を緩和速度変化へ換算し、曲線面積から脳血液量（CBV）を推定する。逆畳み込みなどにより脳血流量（CBF）と平均通過時間（MTT）を求める。
- 肝細胞特異性造影剤：動態相に加え、肝細胞への取り込みと胆汁排泄を遅い相でみる。肝機能、撮像時期、輸送体の影響を受ける。
- SPIO：超常磁性酸化鉄により、主にT2/T2\*を短縮して信号を低下させる。製剤の利用可能性は時期・地域で異なる。

# 5. DWI・ADC・DTI：最頻出の機能画像

## 5-1. DWIの原理

> **まずこの理解**：対になった傾斜磁場を「同じ強さで逆向きに押す2回の印」と考える。2回の間に動かなかった水素原子核では印が打ち消し合うが、移動した水素原子核では打ち消し切れず、信号が減る。これは比喩であり、正確には、2つの拡散検出用傾斜磁場が位置に応じた位相を与え、間に拡散したスピンほど再収束後の位相分散が大きくなる。

**体内で何が起こるか**：水分子は熱運動によって不規則に移動する。細胞腫脹、細胞密度の上昇、粘稠な内容物などで水の見かけの移動が小さくなると、拡散制限として観察される。

**装置が何をするか**：装置は対になった拡散検出用傾斜磁場（MPG）を加える。静止スピンは2つ目のMPGで再収束するが、間に移動したスピンは完全には再収束せず、位相がばらついて信号が低下する。拡散への感度はb値で表す。

**画像にどう表れるか**：自由に拡散する水は高b値DWIで信号が下がる。拡散が制限された組織は信号低下が小さいため、周囲に比べて高信号に見え、ADCは低値になる。

矩形のMPGでは、b値は傾斜磁場強度の二乗、各パルスの長さ、2つのパルス間隔で決まる。数式では

`b = γrad² G² δ² (Δ − δ/3)`

と表す。`γrad` は角磁気回転比、Gは傾斜磁場強度、δは各傾斜磁場パルスの持続時間、Δは2つの傾斜磁場パルスの開始間隔である。Gは二乗で効くため、単純な「傾斜磁場強度×時間」ではない。臨床でb値は通常s/mm²、ADCはmm²/sで表すため、式へ代入するときは傾斜磁場、長さ、時間の単位をそろえる。

単一指数モデルでは、b値を上げたときの信号低下からADCを求める。

`S(b) = S0 exp(−b × ADC)`

2点なら

`ADC = −ln[S(b)/S0] / b`

一般の2点 `b0, b1` では `ADC = ln(Sb0/Sb1)/(b1−b0)` となる。

**試験の要点**：DWI高信号だけでは拡散制限と断定できない。T2が長い病変も高信号になり得るため、ADC低値を必ず確認する。b値を上げると拡散強調は強くなるが、全体のSNRは下がり、歪みや雑音の影響が増える。

## 5-2. DWIとADCの4象限

| DWI | ADC | 解釈の出発点 | 例・注意 |
|---|---|---|---|
| 高 | 低 | 真の拡散制限を支持 | 急性梗塞、膿瘍、高細胞性腫瘍など。ただし重なりあり |
| 高 | 高〜正常 | T2透過効果（T2シャインスルー） | T2の長い病変。ADCを見ずに拡散制限としない |
| 低 | 低 | T2暗黒化（T2ブラックアウト）または低いプロトン密度・SNR | 出血、鉄、強い線維化など。画質も確認 |
| 低 | 高または不安定 | 自由拡散、または低SNRのためADC計算自体が不確か | CSF、壊死・嚢胞など。b0画像、T2強調像、雑音下限、元画像と照合 |

ADCは純粋な細胞密度計ではない。b値、灌流、TE、脂肪抑制、雑音下限、壊死、粘稠度、治療、時間経過で変わる。絶対値の閾値は、臓器、装置、撮像条件をまたいで安易に共通化しない。

### 典型的な出題のひっかけ

- 急性梗塞：一般に発症早期からDWI高・ADC低。慢性期にはADCが上昇し得る。
- 膿瘍腔：粘稠な細胞・蛋白内容で制限し得るが、すべての嚢胞性病変を一律に分けられるわけではない。
- 類表皮嚢胞：DWI高・ADC低が手がかり。くも膜嚢胞は通常、自由拡散を示す。
- 高細胞性腫瘍：低ADC傾向だが、腫瘍種や悪性度をADC単独で確定しない。

標準的な1回励起SE-EPI DWIは速い一方、側頭骨、頭蓋底、金属近傍で磁化率歪みが強い。非EPI DWI（TSE系など）は歪みが少なく小病変を描きやすいため、特に中耳真珠腫などで有用である。ただし、撮像時間、体動、撮像範囲との間に兼ね合いがある。

## 5-3. IVIM、DTI、トラクトグラフィ

低b値には毛細血管内の微小灌流が混ざる。IVIMは概念的に

`S/S0 = (1−f) exp(−bD) + f exp(−bD*)`

と表し、真の拡散係数D、灌流成分比f、偽拡散係数D\*を分ける。ただし、推定は不安定で、b値の配置、雑音、体動に強く依存する。

DTIは複数方向のDWIから拡散テンソルを推定する。FAは0に近いほど等方性、1に近いほど一方向性が強い。主固有ベクトルを連結したトラクトグラフィは**推定された経路**であり、交差・接近する線維、浮腫、腫瘍、低SNR、追跡閾値に弱い。実在する線維束の証明ではない。

# 6. 血流・灌流・機能を撮る

## 6-1. MRAは3つの原理に分ける

| 方法 | 主要原理 | 得意 | 典型的な注意点 |
|---|---|---|---|
| TOF | 飽和した静止組織へ、まだ飽和していない血液が流入して高信号 | 頭蓋内動脈、非造影 | 遅い血流・面内血流の飽和、乱流・狭窄後の信号低下、T1高信号物質 |
| PC | 一対の傾斜磁場後の位相差が速度に比例 | 方向・流速・流量定量、静脈 | 速度エンコード値（VENC）が低すぎると位相折り返し、高すぎると遅い血流への感度低下 |
| 造影MRA（CE-MRA） | Gdによる血液T1短縮＋高速3DスポイルドGRE | 広範囲を短時間で撮像でき、TOFの飽和に比較的左右されにくい | 造影剤注入と撮像の時機、静脈の重なり、体動、腎機能・造影反応 |

SE系では、速い血流が90°パルス、180°パルス、信号読み出しの間にスライス外へ出ると、必要なパルスをすべて受けないため低信号となる。これを血流による信号欠損（フローボイド）という。一方、GRE/TOFでは、まだRFを受けていない流入血液が高信号になり得る。**血流は常に高信号または低信号なのではなく、受けるパルスとスライス内の滞在時間で決まる。**

PC-MRIでは、移動するスピンに一対の傾斜磁場を加えると、速度に比例した位相差が残る。関係式は `Δφ = γrad M1 v` であり、`M1` は傾斜磁場の一次モーメント、`v` は速度を表す。一般的な表示規約では `v = (Δφ/π) × VENC` と対応させ、実速度の絶対値がVENCを超えると位相が折り返す。VENCが高すぎると小さな速度差を表現しにくい。静止成分は差分で消え、移動スピンの位相差が残る。**速度依存の位相差を測る方法であり、ドプラ効果を測る方法ではない。**

2D TOFはスライスごとに未飽和血液を受け入れるため、遅い血流や広範囲の撮像に比較的強いが、スライス間の不整合と面内分解能に限界がある。3D TOFは薄い連続スライスと高分解能に有利だが、厚いスラブ内で遅い血流や面内血流が飽和する。複数重複薄スラブ収集法（MOTSA）は、複数の薄いスラブを重ねて両者を折衷する。

TOFのMIPはわかりやすいが、血管の重なり、飽和、部分容積効果により狭窄を過大・過小評価し得る。必ず元画像を確認する。

## 6-2. 代表的な機能・定量MRI

- **ASL**：上流血液のスピンを磁気的に標識し、標識画像と対照画像の差からCBFを推定する。造影剤は不要である。血液到達時間、低SNR、標識効率に注意する。
- **DCE**：造影T1強調像の時系列から増強曲線や薬物動態の指標を推定する。造影剤注入、時間分解能、T1マッピング、解析モデルに依存する。
- **DSC**：造影剤の初回通過によるT2\*信号低下を測る。造影剤漏出の補正、動脈入力関数、到達遅延の影響を受ける。
- **BOLD機能的MRI（fMRI）**：神経活動に伴うCBF増加が酸素消費増加を上回ると、脱酸素化ヘモグロビンが減り、T2\*信号が相対的に上昇する。この時系列を血行動態反応と統計解析で評価する**間接指標**である。
- **MRE**：外部振動によるせん断波を、運動エンコード用傾斜磁場で検出し、逆問題を解いて硬さの分布図を作る。肝線維化が代表的な用途である。炎症、うっ血、食後、鉄沈着、加振器との接触状態も値に影響する。
- **MRS／化学シフト画像（CSI）**：化学シフトを代謝物スペクトルとして測る。脳ではN-アセチルアスパラギン酸（NAA）、コリン（Cho）、クレアチン（Cr）、乳酸、脂質などが代表的である。TE、ボクセル、シミング、部分容積効果に依存するため、ピーク比だけで診断しない。
- **LGE**：Gdが細胞外腔の拡大部や洗い出し遅延部に相対的に残る時相で、IR/PSIRにより正常心筋の信号をゼロにし、瘢痕・線維化を高信号にする。虚血性病変では心内膜下から全層性へ広がる冠動脈支配に沿った分布、非虚血性病変では心筋中層や心外膜下の分布が手がかりとなるが、臨床情報と他の撮像法を統合する。

## 6-3. MRCPと強いT2強調

胆汁・膵液などの静止液を、非常に長いTEによる強いT2強調で高信号にし、背景信号を抑える。2D厚スラブ法は速いが、構造の重なりと部分容積効果が多い。3D薄スラブ法は詳細な描出とMPRに優れるが、体動に弱い。MIPだけでは小結石や狭窄が隠れることがあるため、薄い元画像を併読する。

# 7. MRIの画質と撮像条件の兼ね合い

## 7-1. SNRの基本

> **まずこの理解**：1ボクセルを「信号を受け取る升」と考えると、升を大きくするほど多くの信号が入り、画像は滑らかになるが、細部は粗くなる。小さくすると細部は見やすいが、受け取る信号が減ってざらつく。これは比喩であり、正確には、単純化した条件では1ボクセルの信号はボクセル体積におおむね比例し、雑音との比であるSNRは小さいボクセルほど低下する。

**体内で何が起こるか**：組織はそれぞれ異なる強さと時間変化をもつMR信号を出す。撮像条件は、どの時点の信号差を強調するかを変える。

**装置が何をするか**：装置はTR、TE、フリップ角、FOV、マトリックス、スライス厚、NEX、受信帯域幅などを変え、収集する信号量と標本化の細かさを調整する。

**画像にどう表れるか**：ある条件を改善すると別の条件が悪化することが多い。たとえば、ボクセルを小さくすれば公称分解能は上がるがSNRは下がり、NEXを増やせばSNRは上がるが時間が延びる。

単純化すると、SNRはボクセル体積とコイル感度に大きく依存し、NEXに対して `√NEX` で増える。受信帯域幅を広げると、1画素当たりの雑音が増えてSNRは低下する。一方で、化学シフト、EPI歪み、読み出し時間を減らせる。以下の表は**他条件を一定とした一次的な傾向**であり、定常状態、再構成、装置制御により単調に変わらない場合がある。

| 変更 | 信号・コントラスト | 分解能 | 時間 | アーチファクト・安全 |
|---|---|---|---|---|
| TR↑ | T1差↓、SNR↑傾向 | 原則不変 | ↑ | RF/SARは低下しやすい |
| TE↑ | T2/T2\*差↑、全体信号↓ | 原則不変 | 条件依存 | 磁化率・体動の影響↑ |
| フリップ角↑ | スポイルドGREではエルンスト角までは信号↑。飽和とT1強調は強くなりやすいが、信号とコントラストは組織T1・TR依存で単調ではない | 原則不変 | 原則不変 | RF負荷/SAR↑、B1依存↑ |
| FOV↓（マトリックス一定） | ボクセル↓でSNR↓ | 画素寸法↓、公称面内分解能↑ | 原則不変 | 折り返し危険↑ |
| マトリックス↑（FOV固定） | ボクセル↓でSNR↓ | 画素寸法↓、公称面内分解能↑ | 位相方向なら↑ | ギブス・アーチファクト↓、体動混入の機会↑ |
| スライス厚↓ | SNR↓ | z軸分解能↑ | 2Dではスライス数次第 | 部分容積効果↓ |
| NEX↑ | SNR `∝√NEX` | 不変 | `∝NEX` | 体動が平均化されることもある |
| 受信BW↑ | SNR↓ | 化学シフトの画素ずれ↓ | 読み出し時間短縮 | 歪み↓、最短TE短縮、騒音↑の場合 |
| ETL↑ | エコーの混合 | T2ぼけ↑ | ↓ | 再収束パルス条件によりSARが増え得る、FSEで脂肪高信号 |
| 並列撮像のR↑ | SNR `1/(g√R)` | 公称分解能は維持 | ↓ | 残留折り返し、EPI歪み↓ |
| b値↑ | DWIの拡散強調↑、信号↓ | 公称分解能は同じ | TEが延長し得る | 歪み、渦電流の影響、雑音下限 |
| B0↑ | SNR↑が期待 | 高分解能化が可能 | 同等または短縮可能 | T1延長、SAR・化学シフトの周波数差・磁化率効果・B1むら↑ |

**試験の要点**：条件変更問題では、必ず「他条件が一定」という前提を確認する。分解能、SNR、撮像時間、アーチファクト、安全性の5項目を同時に追う。とくに、マトリックス増加は分解能↑・SNR↓・位相方向なら時間↑、NEX増加はSNRが `√NEX` に比例・時間がNEXに比例、受信BW増加はSNR↓・化学シフトと歪み↓が基本である。

### 受信帯域幅の頻出ポイント

- 広いBW：短い標本化間隔、短い読み出し時間・エコー間隔となり、化学シフトと歪みは減るが、SNRは下がる。
- 狭いBW：SNRは上がるが、化学シフト、金属・磁化率による歪みが増え、最短TEが長くなり得る。
- **BWを広げれば空間分解能そのものが必ず上がるわけではない**。マトリックス、FOV、傾斜磁場、標本化を合わせて考える。

|---|---|---|---|
| 体動ゴースト | 直交格子状の収集では主に位相方向に反復像 | 呼吸、拍動、長時間撮像 | 固定・説明、呼吸／心電図同期、位相方向変更、高速化、放射状収集、回転ブレード状収集（PROPELLER）、飽和帯 |
| 血流・拍動ゴースト | 血管やCSFから位相方向に反復像 | 拍動性血流、長いTE | 流れ補正、飽和帯、同期、位相方向変更 |

| 磁化率アーチファクト | 空気・金属・血液産物の周囲に信号欠損、歪み、ブルーミング | GRE/EPI、高いB0、長いTE、狭いBW、大きなボクセル | SE/FSE、短いTE、小さいボクセル、シミング。BW↑は主に歪みを低減。観察角傾斜法（VAT）、金属補正用スライスエンコード（SEMAC）、複数周波数帯収集（MAVRIC）は金属対策 |

| B1・誘電体シェーディング | 広い陰影や局所信号低下 | 高いB0、腹部、大きな体格 | B1シミング、多重送信、撮像法の調整。誘電体パッド／RFシムパッドは装置・製品との適合と使用条件を確認し、辺縁の局所加熱に注意 |
| 交差干渉 | 隣接する2Dスライスの信号低下 | スライスの重なり、不完全なスライス形状 | スライス間隔、交互収集、3D撮像。交互収集中の体動では奇数・偶数スライス群が交互にずれ得る |
| 渦電流 | DWIの位置ずれ、せん断、拡大・縮小 | 強く速い傾斜磁場 | 磁気遮蔽、事前補償、補正、位置合わせ |

| スパイク／ヘリンボーン | 画像全体に縞や斜線 | k空間の単一点異常 | 生データとコイルを確認、再撮像、保守点検 |

アーチファクト問題は、まず **方向**（位相方向か読み出し方向か）、次に **撮像法への依存性**（GRE/EPIかSEか）、最後に **条件を変えたときの増減**をみる。

# 9. MRI安全

MRIは電離放射線を使わないが、「無害」ではない。安全上の危険を、静磁場、時間変化する傾斜磁場、RF磁場、装置冷却系、造影剤に分けて考える。

| 要因 | 主な危険 | 基本対策 |
|---|---|---|
| 静磁場B0とその空間勾配（漏洩磁場） | 強磁性物体の吸着・飛来、体内機器の移動・回転、機器誤作動 | 入室者と物品の確認、MR表示と条件の照合、区域管理、入室直前の最終確認 |
| 時間変化する傾斜磁場 | 大きな騒音、末梢神経刺激 | 聴覚保護、規制モード、患者との連絡手段 |
| RF磁場B1 | 全身・局所加熱、導電ループや接触部の熱傷、体内機器・導線の加熱 | SAR・時間平均RF磁場指標（B1+rms）の管理、ケーブルを皮膚から離す、皮膚同士の接触を避けて緩衝材を入れる、機器条件の遵守 |
| 冷媒・クエンチ（該当装置） | 酸欠、冷気、圧力上昇、非常時対応 | 機種、仕様、法令、施設設計に応じ、排気管、緊急排気、圧力逃がし、必要時の酸素濃度計、避難手順・訓練を整える。少量冷媒型ではクエンチ排気管が不要な場合があり、永久磁石型は冷媒を使わない。緊急停止と磁石のクエンチを混同しない |
| Gd造影剤 | 急性反応、血管外漏出、腎性全身性線維症（NSF）、体内残留への配慮 | 適応、製剤グループ、腎機能、妊娠を評価し、必要最少量を用いて急性反応へ備える |

超電導MRIのB0は通常24時間存在し続け、操作卓や一般電源を切っても強磁性物体の吸着・飛来の危険は残る。SARは厳密にはコイル、体格、撮像法で決まるが、概念的にはB0、フリップ角、RFパルスの使用割合が高いほど増え、FSEの多数の再収束パルスは注意を要する。未使用・未接続の表面コイル、心電図導線・電極などの導電物を患者と一緒に装置開口部へ残さず、必要な接続と絶縁を撮像前に目視確認する。

**MR Safe（MR安全）**はすべてのMR環境で既知の危険がないもの、**MR Conditional（条件付きMR対応）**は記載された磁場強度、空間勾配、SAR・B1+rms、コイル、位置、撮像時間などの条件下だけ安全なもの、**MR Unsafe（MR危険）**はMR環境で危険をもたらすものである。たとえば3 TでMR Conditionalと確認されても、表示条件に記載のない1.5 Tや0.55 Tが自動的に安全とは限らない。安全状態が不明な機器を正式にMR Unsafeと再分類するわけではないが、「たぶん大丈夫」と撮像可能とも仮定しない。原則として撮像を保留し、製品を同定して条件を照合する。なお未解決なら施設手順に従い、責任あるMR医師・MR安全担当者が文書化した危険評価と利益・危険の比較判断を行う。

心臓ペースメーカー、人工内耳、脳動脈瘤クリップなどは、一律に「絶対禁忌」ではない。製品を正確に同定し、MR Conditionalの条件、施設の手順、必要な監視と機器設定を満たせるかで判断する。体外機器、貼付薬、衣類、入れ墨、体内異物も確認対象である。

### 造影剤安全の試験対策

- 重篤な腎障害ではNSFの危険を考える。米国放射線医学会（ACR）分類では、グループIはNSFとの関連が比較的強く、グループIIは極めて低い危険と評価される製剤群、グループIIIはデータが限定的な分類枠であり、単純な線状型・環状型の構造分類と同義ではない。ACR 2026の分類表では、グループIII欄は「現時点で該当製剤なし（2024年4月時点）」である。ガドキセト酸ナトリウムは2024年にグループIIへ再分類された。グループII*のガドピクレノールは暫定分類で、施設判断によりグループIIまたはIII相当として扱えるとの注記がある。分類は改訂され得るため、国内採用状況、添付文書、現行表を確認する。
- 国内の日本医学放射線学会・日本腎臓学会第3版（2024）では、長期透析、推算糸球体濾過量（eGFR）30 mL/min/1.73 m²未満の慢性腎不全、急性腎障害（AKI）では、可能な限りGdを避けて代替検査を検討する。一方、代替が困難なら検査を一律に断念せず、適正使用量を守り、反復時は可能な限り間隔を空け、利益と危険を比較して判断する。
- Gdは投与後に微量が体内へ残留し得る。臨床的必要性、反復回数、代替法を考え、必要最少量とする。
- 妊娠中は通常のGd投与を避け、期待される利益が胎児への不確実な危険を明確に上回る場合だけ検討する。ACR等では、授乳中に通常量を投与した後の一律の授乳中断は不要とされるが、国内添付文書、施設方針、本人の選択を優先する。急性反応と血管外漏出も個別に評価する。
- Gd造影後にSTIRを避けるのは**安全性の問題ではなく、T1が短縮した増強組織まで抑制され、評価しにくくなるという画質上の問題**である。

# 第II部　CT

# 11. CTは何を画像にしているか

## 11-1. X線が検出器へ届くまで

CTは、体を通り抜けたX線の「弱くなり方」を多くの方向から測る。骨などX線を強く弱める物質の後ろでは、検出器に届くX線が少ない。多方向の「X線の影」を組み合わせると、どの位置でどれだけX線が弱められたかを断面図にできる。この処理が「再構成」であり、画像の元は線減弱係数 `μ` である。

```text
X線管
  ↓  制動X線＋特性X線（多色X線）
付加フィルタ／ボウタイフィルタ
  ↓  低エネルギー成分を除き、体形に合わせて線質・強度を整える
患者
  ↓  光電吸収＋コンプトン散乱などで減弱
検出器 → データ収集系（DAS）
  ↓  入射強度 I を電気信号へ
対数変換  p = −ln(I/I0)
  ↓  各方向の線積分（投影データ）
フィルタ補正逆投影（FBP）／逐次近似再構成（IR）／深層学習再構成（DLR）
  ↓  μの分布 → CT値（HU）へ変換 → ウィンドウ表示
```

単色で細いX線ビームを理想化したベール・ランベルトの法則は

`I = I0 exp(−∫ μ dl)`

したがって

`p = −ln(I/I0) = ∫ μ dl`

となる。ここで `I0` は物体に入る前の強度、`I` は通過後の強度である。実際には多色X線、散乱線、検出器の応答、ビームハードニング（線質硬化）があるため、それぞれの補正が必要になる。

### 主な相互作用

- **光電効果**：低エネルギー、高原子番号で相対的に増え、骨やヨードのコントラストに重要である。ヨードのK吸収端は**33.2 keV**であり、80 kVpではない。低kVpでヨード造影効果が上がるのは、X線スペクトルの実効エネルギーがK吸収端に近づき、ヨードの質量減弱係数が相対的に増えるためである。
- **コンプトン散乱**：診断用X線のエネルギー域における軟部組織で重要で、主に電子密度に依存する。散乱線はコントラスト低下、アーチファクト、不要な被ばくに関与する。

## 11-2. CT値（HU）

`HU = 1000 × (μ − μ水) / μ水`

| 物質・組織 | 代表的なHUの方向 | 注意 |
|---|---:|---|
| 空気 | 約−1000 | 校正・部分容積で変動 |
| 肺 | 大きく負 | 吸気、病変、再構成で変動 |
| 脂肪 | およそ−100前後 | 種類・部分容積効果で幅 |
| 水 | 0 | 基準 |
| 軟部組織 | 数十HU | 造影、脂肪、鉄などで変動 |
| 急性血腫 | 通常は高吸収 | ヘマトクリット・時間・貧血で変動 |
| 骨・石灰 | 高い正値 | kVp、再構成カーネル、部分容積効果で変動 |

CT値は絶対不変ではない。kVp、ビームハードニング、装置の校正、再構成法、造影の有無、関心領域（ROI）の大きさ、患者の体格に依存する。小病変では部分容積効果を避け、同じ造影時相・撮影条件で比較する。

## 11-3. ウィンドウは「表示」であって再構成ではない

ウィンドウレベル（WL）は表示するCT値の中心、ウィンドウ幅（WW）は表示するCT値の幅である。概念的な表示範囲は

`表示下限 = WL − WW/2`、`表示上限 = WL + WW/2`

- 狭いWW：小さなHU差を大きな濃淡差として表示するが、雑音も目立つ。
- 広いWW：広いHU範囲を表示でき、雑音は目立ちにくくなるが、低コントラストの差も見えにくい。
- **WWを広げても、画像データに含まれる物理的な雑音は減らない**。
- 画面上の拡大は、表示画像の拡大と画素補間である。元データの空間分解能を超えて、新しい細部を作り出すことはできない。

# 12. 装置構成・幾何学・撮影方式

## 12-1. 主要部品

- **X線管**：管電圧（kVp）がX線のエネルギースペクトルを、管電流（mA）と照射時間がフォトン数を主に決める。焦点の大きさ、熱容量、回転速度が制約になる。
- **コリメータ**：X線の照射範囲を制限する。患者の前にあるコリメータと、検出器側で散乱線やチャンネル間の信号混入を抑える隔壁を区別する。
- **ボウタイフィルタ**：身体周辺の薄い部分へのX線を減らし、検出器が扱う信号幅、雑音、線量を整える。患者が回転中心（アイソセンタ）からずれると、自動露出制御（AEC）、ボウタイフィルタの適合、画質、線量が同時に悪化し得る。
- **検出器**：通常のエネルギー積分型検出器は、シンチレータでX線を光に変え、フォトダイオードで電気信号に変えて、入射エネルギーを積算する。
- **データ収集系（DAS）**：検出器信号を増幅し、標本化してデジタルデータに変換する。
- **スリップリング**：ガントリの連続回転を可能にし、ヘリカルCTの基盤となる。

## 12-2. 逐次撮影、ヘリカル撮影、多列検出器CT

逐次撮影は、食パンを1枚ずつ切るように、寝台を止めた状態で断面ごとに撮る。ヘリカル撮影は、X線管が回り続ける間に寝台を動かし、身体をらせん状になぞる。多列検出器CTでは一度に多くのz方向データを取得できるため、短時間で薄い断面を広範囲に得られる。

- **逐次撮影**：1回転ごとに寝台を止める、または次の位置へ移動する。ヘリカル補間に必要な追加照射はないが、実際のX線ビーム端の半影による照射幅の広がりは起こり得る。限定範囲や心電図同期心臓CTで利点がある。
- **ヘリカル撮影**：X線管が連続回転しながら寝台が移動し、投影データの軌跡はらせん状になる。1回の呼吸停止中に立体データを集められ、任意位置の再構成やCT血管撮影（CTA）に有利である。
- **多列検出器CT（MDCT）**：z方向に複数の検出器列を持ち、1回転で広い範囲を取得する。薄い等方性ボクセルのデータ、高速な範囲撮影、多断面再構成（MPR）や三次元（3D）表示の基盤になる。
- **広範囲検出器CT**：臓器が検出器のz方向撮影幅に収まれば、1回転で臓器全体を撮影でき、心臓や灌流撮影に有利である。コーン角による影響と大量のデータに配慮する。
- **2管球CT**：2組のX線管と検出器を持つ。高い時間分解能、2種類のエネルギーを用いる撮影、高ピッチ撮影などに利用する。

総検出幅は概念的に `N × T`（N：有効チャンネル数、T：患者の回転中心に投影した公称チャンネル幅）である。検出器上の物理幅とは拡大率の分だけ異なり、実際のX線ビームには半影もある。「検出器列数」「DASチャンネル数」「同時再構成スライス数」は、飛躍焦点や再構成法の影響があるため、常に同じとは限らない。

### その他の撮影方式

- **位置決め画像**：固定したX線管で投影像を作り、撮影範囲、AEC、中心合わせを決める。腕の位置、投影方向、回転中心からのずれは、管電流変調に影響する。
- **シネ／動態撮影**：寝台を固定するか限定範囲で往復し、繰り返し撮影する。試験注入、灌流、動態を評価できるが、時間分解能と局所の累積線量を管理する。
- **部分回転撮影**：再構成に必要な約180°＋ファン角のデータを使い、時間分解能を上げる。心臓CTの基盤である。
- **CT透視**：同一断面を反復撮影し、生検や治療手技を誘導する。局所線量に注意する。

## 12-3. ヘリカルピッチ

ピッチは「X線管が1回転する間に、寝台がX線ビーム幅の何倍進むか」を表す。ピッチ1なら総ビーム幅と同じ距離、ピッチ2なら約2倍の距離を進む。大きくすると速く広く撮れる一方、z方向の画質、雑音、線量は補間法や装置の出力制御によって変わる。

多列検出器ヘリカルCTのピッチは

`ピッチ = 1回転あたりの寝台移動 / 総コリメーション (N × T)`

ヘリカルCTでは、目的の断面を直接通るすべての投影データがそろうとは限らないため、らせん軌道上の前後のデータを補間して画像を作る。古典的な180°補間は比較的薄いスライス感度プロファイル（SSP）が得られるが雑音が増えやすく、360°補間はデータ平均が増えて雑音は下がるがSSPが厚くなりやすい。現代の装置はzフィルタやコーンビーム再構成などを使うため、ピッチと再構成法がSSPと雑音を一緒に変える。

- **オーバービーミング**：公称コリメーションより実際のX線ビームが半影の分だけ広いこと。総コリメーションが狭いほど、照射したX線を画像に利用する幾何学的効率が悪化しやすい。
- **オーバーレンジング**：ヘリカル補間のため、設定した撮影範囲の前後にも照射すること。短い撮影ほど相対的な寄与が大きく、動的zコリメーションは主にこれを減らす。

### ピッチ問題の正しい解き方

1. **何を固定しているか**を見る。
2. mAと回転時間を固定した単純モデルでは、ピッチ↑で同一点を照射する回数が減り、`容積CT線量指数（CTDIvol） = 加重CT線量指数（CTDIw） / ピッチ`。
3. しかし実効mAs一定、自動露出制御（AEC）、X線管出力の補償ではmAが変わり、線量は単純に下がらない。実効mAsは一部メーカーで用いる概念で、概ね `(1回転あたりのmAs) / ピッチ`。真の管電流時間積そのものではない。
4. 高ピッチはz方向の標本化を粗くし得る。現代の補間や2管球高ピッチ撮影など例外があるため、「ピッチ↑ならz分解能が必ず上がる」は誤り。

## 12-4. 撮影視野と表示・再構成視野

- **撮影視野（SFOV）**：投影データを取得・再構成できる物理的な範囲。被写体が外れると、データの欠損による切れ・濃度むら（トランケーション）が生じる。
- **表示・再構成視野（DFOV）**：画像として表示・再構成する範囲。行列数が一定なら `画素寸法 = DFOV / 行列数`。
- DFOVを小さくすると画素による標本化は細かくなるが、検出器、焦点、幾何学、再構成カーネルで決まる装置の真の分解能を超えることはできない。

# 13. 投影データから断層像へ：画像再構成

多方向から得た投影データは、さまざまな角度から見た「X線の影」である。これをそのまま重ねるだけでは画像がぼけるため、ぼけを補うフィルタを使う方法や、予測画像と実測データを何度も比べて修正する方法で断層像を作る。

## 13-1. 単純な逆投影だけではぼける

各方向の投影データをそのまま逆投影すると、値が線上へ広がってぼける。フィルタ補正逆投影（FBP）は、投影データに高周波を強めるフィルタをかけてから逆投影し、輪郭を回復する。高周波強調フィルタ／カーネルは空間分解能を上げる一方、雑音も増幅する。

## 13-2. 現代の再構成法

| 方法 | 考え方 | 長所 | 注意 |
|---|---|---|---|
| FBP | フィルタをかけた投影データを解析的に逆投影 | 高速、画像の質感を予測しやすい | 低線量で雑音・線状アーチファクトが増える |
| 逐次近似再構成（IR） | 予測した投影データと観測データの差を反復して小さくする | 雑音・アーチファクト低減、線量最適化 | 強度設定で画像の質感・分解能が変わり、メーカー差がある |
| モデルベース逐次近似再構成 | 装置の光学特性・雑音統計を詳細にモデル化 | 高いアーチファクト・雑音低減 | 計算量、非線形な見え方 |
| 深層学習再構成（DLR） | 学習済みモデルで雑音、画像の質感、細部を再構成 | 低雑音と自然な質感を目指せる | 学習範囲、メーカー、強度設定、診断目的に依存する。病変を「創作しない」と無条件に仮定しない |

再構成は線形とは限らない。線量、患者の体格、コントラスト、病変を見つける目的ごとに、単なる標準偏差だけでなく低コントラスト検出能と画像の質感を評価する。

## 13-3. データ収集、再構成、表示を混ぜない

| 段階 | 例 | 後から変更できるか |
|---|---|---|
| データ収集 | kVp、mA、回転時間、コリメーション、ピッチ、撮影長 | 原則として再撮影が必要 |
| 再構成 | スライス厚、再構成間隔、DFOV、カーネル、IR／DLRの強度 | 生データがあれば再構成できることがある |
| 表示・後処理 | WL／WW、拡大、多断面再構成（MPR）、最大値投影（MIP）、ボリュームレンダリング（VR）、スペクトラルデータから作る仮想単色X線画像（VMI）・物質マップ | MPRなどには連続した体積元データ、VMIなどには保存されたスペクトラルデータが必要。任意の画像だけからは作れない |

試験では「ウィンドウ幅を広げて雑音低減」「表示を拡大して真の分解能向上」のように、段階を混ぜた選択肢が狙われる。

# 14. CT画質の4軸

撮影・再構成条件の調整だけで、「細かいもの」「淡い濃度差」「動くもの」をすべて代償なく良くすることはできない。例えば、薄いスライスや高周波強調カーネルは細部を見やすくするが雑音を増やし、X線光子を増やせば雑音は減るが線量が増える。まず何を診断したいかを決め、空間分解能、低コントラスト分解能、時間分解能、雑音の釣り合いを取る。

## 14-1. 面内空間分解能

焦点の大きさ、検出器開口、撮影の幾何学、投影方向数、体動、DFOV／行列数、再構成カーネルで決まる。変調伝達関数（MTF）は、空間周波数ごとのコントラスト伝達を表し、MTF50やMTF10などで評価する。

## 14-2. z軸分解能

検出器コリメーション、ヘリカルピッチと補間、再構成スライス厚・カーネルに依存する。スライス感度プロファイル（SSP）の半値幅（FWHM）などで評価する。

- 薄いスライス：部分容積効果↓、z分解能・MPR／3D表示↑、雑音↑、データ量↑。
- 厚いスライス：雑音↓。病変が十分大きければコントラスト対雑音比（CNR）と低コントラスト検出能が上がり得るが、小病変では部分容積効果によりコントラストと検出能が下がり得る。z分解能↓、部分容積効果↑。
- 再構成間隔を狭くして重なりを増やしても、新しい独立分解能を作るわけではないが、MPR／3D表示の段差と小病変の位置依存を減らす。線量は増えない。

## 14-3. 低コントラスト分解能

雑音、CNR、病変の大きさ、スライス厚、線量、平滑カーネル、IR／DLRに強く依存する。低コントラスト病変には、単純な高MTFより十分なX線光子数と適切な雑音の質感が重要である。高周波強調カーネルは輪郭を強調するが雑音を増やし、低コントラスト検出を悪化させ得る。

## 14-4. 時間分解能

1画像の時間分解能は、回転時間、部分回転撮影の幾何学、X線管の数、複数心拍データを使う再構成などで決まる。1管球・1心拍分の再構成では、回転中心における時間分解能は一般に約1/2回転、2管球CTでは装置の幾何学により約1/4回転である。完全なファンビームデータに必要な取得角度は180°＋ファン角で、撮影視野内の位置、補間・再構成、体動補正により実効時間分解能は変わる。z方向の撮影幅は、臓器全体を同じ時相で覆えるか、検査全体を撮り終えるまでの時間に影響するが、1画像の時間分解能そのものとは分けて考える。回転時間を短くすると体動は減るが、mA固定ならmAsが減って雑音が増える。mAsを維持するには、より大きなX線管出力が必要となる。

## 14-5. 撮影・再構成条件を変えたときの一覧

| 変更 | 画質 | 線量 | 時間・その他 |
|---|---|---|---|
| mAs↑ | 雑音は `∝1/√mAs` で低下、信号対雑音比（SNR）↑。FBP・固定再構成条件では空間分解能は原則不変だが、非線形なIR／DLRでは条件依存 | `∝mAs` で↑ | X線管の発熱↑ |
| kVp↑ | X線の透過力↑、フォトン不足↓、ヨードコントラスト↓ | mAs固定なら概ね↑。AEC使用時などは条件依存 | ビームハードニング↓、大体格に有利 |
| kVp↓ | ヨードコントラスト↑ | 適切なmA最適化で低減可能 | 大体格で雑音・フォトン不足、X線管出力限界 |
| 回転時間↓ | 体動によるぼけ↓ | mA固定ならmAs／線量↓ | フォトン不足、心臓CTに有利 |
| スライス厚↓ | z分解能↑、雑音↑ | データ収集条件が同じなら原則不変 | データ量↑、部分容積効果↓ |
| 高周波強調カーネル | 輪郭・MTF↑、雑音↑ | 不変 | 低コントラスト検出能↓ |
| 平滑カーネル | 雑音↓。十分大きい低コントラスト物体の検出能↑が期待されるが、小病変ではぼけに注意 | 不変 | 輪郭・高コントラスト分解能↓ |
| DFOV↓ | 画素による標本化↑ | 不変 | 装置のMTF以上にはならない |
| 再構成間隔↓ | MPRの連続性↑ | 不変 | 画像枚数↑ |
| 撮影長↑ | 画質は改善しない | 線量長積（DLP）↑ | 範囲の正当化が必要 |
| 多相化 | 時相情報↑ | 総線量↑ | 必要相だけ選ぶ |
| ピッチ↑ | z方向の画質は条件依存 | 1回転あたりのmAs固定ならCTDIvol↓、AEC使用時は単純でない | 撮影速度↑ |

### mAsの平方根則

線量を1/2にすると、他条件一定なら雑音は `√2 ≈ 1.41` 倍。雑音を1/2にするにはmAsを4倍に要する。**雑音はmAsに反比例ではない**。

## 14-6. 自動露出制御（AEC）と管電流変調

AECは「常に線量を下げる機能」ではなく、設定した目標画質を患者のX線減弱に合わせて達成するため、mAを変える機能である。IR／DLRを導入した後も、AECの目標値を診断目的ごとに再検証する。

- **長軸方向変調**：位置決め画像からz位置ごとの減弱を予測してmAを変える。
- **角度方向変調**：1回転中の前後・左右方向でmAを変える。
- **複合変調**：両者を組み合わせる。
- 目標値の表し方は、画質基準mAs、雑音指数、基準画像などメーカーで異なる。
- 患者の中心ずれ、腕が体幹横にある状態、不適切な位置決め画像の方向・呼吸・金属は、mAの過不足と画質不均一を生む。

### 頭蓋底と金属の頻出解答

- **後頭蓋窩**：骨によるビームハードニングとフォトン不足を考える。
- **金属**：単にスライスを厚くするだけでは不十分。**薄層収集＋MAR＋高keV VMI＋適切な体位・中心・X線出力**を組み合わせ、厚めの観察用画像で雑音を抑える。
- 高keV VMIはビームハードニング・金属アーチファクトを減らしやすいが、ヨードコントラストは低下する。低keV VMIはヨードコントラストを上げるが、雑音が増えやすい。

# 16. 造影CT：量・速さ・時相を分ける

## 16-1. 3つの量

`総ヨード量 (gI) = ヨード濃度 (gI/mL) × 注入量 (mL)`

`ヨード投与率 (IDR; gI/s) = ヨード濃度 × 注入速度 (mL/s)`

`注入時間 = 注入量 / 注入速度`

濃度の単位をそろえる。例えば `300 mgI/mL = 0.300 gI/mL`。したがって総ヨード量はgI、IDRはgI/s、`mL ÷ (mL/s)` で注入時間は秒となる。

- 実質臓器の増強量は、体重当たり総ヨード量の影響が大きい。
- CTAの早期動脈ピークでは、IDR、造影剤の時間的なまとまり（ボーラス形状）、心拍出量、撮影時相が重要である。
- 装置が速くなったからといって、造影剤を無条件に減らせるわけではない。撮影時間とボーラス幅を合わせる。
- 生理食塩水による後押しは、静脈内に残る造影剤を押し出して同じヨード量を有効に使い、上大静脈（SVC）周囲のアーチファクトを減らし得る。

## 16-2. 撮影時相の決め方

| 方法 | 考え方 | 長所 | 弱点 |
|---|---|---|---|
| 固定遅延 | 注入開始から一定時間後に撮影 | 簡単 | 心拍出量・注入条件の個人差 |
| 試験注入 | 少量を注入し、時間濃度曲線を測る | 患者ごとの調整 | 追加の造影剤と手順が必要 |
| ボーラストラッキング | 目標血管の関心領域（ROI）が設定CT値に達してから撮影開始 | 実用的な個別化 | 監視間隔、開始後の遅延、ROI、呼吸、低心拍出の影響 |

典型的には、単純CT（非造影）、動脈相、門脈相、平衡相／遅延相を目的に応じて選ぶ。固定秒数の丸暗記より、**どの血管・実質・排泄・線維性間質を見たいか**で説明する。

- **単純CT**：結石、脂肪、石灰化、出血、造影前の基準HU。
- **早期動脈相**：動脈、多血性病変、活動性出血。
- **後期動脈相／膵実質相**：臓器実質と動脈のバランス。
- **門脈相**：腹部実質臓器、門脈系、多くの腫瘍検索。
- **遅延相／平衡相**：線維性間質、造影剤の洗い出し・残留、尿路排泄など。

## 16-3. 造影剤安全

ヨード造影剤では、急性のアレルギー様反応・生理的反応、血管外漏出、甲状腺・腎機能、妊娠、併用薬を考える。腎障害は、造影剤使用後に時間的に関連して生じた造影剤関連急性腎障害（CA-AKI）と、造影剤が原因と考えられる造影剤誘発急性腎障害（CI-AKI）を区別する。管理基準やメトホルミン休薬の扱いは指針、腎機能、急性腎障害の有無で異なるため、現場では最新の米国放射線学会（ACR）、欧州泌尿生殖器放射線学会（ESUR）、国内指針と施設手順を使う。

試験での原則：

- 必要性と代替検査を検討し、診断に十分な造影効果を担保する適正量とし、不必要な過量を避ける。
- 過去の反応の内容と重症度を確認し、前投薬をしても反応の再発はゼロにならない。
- 血管外漏出では注入停止、臨床評価、患肢挙上などを行い、症状に応じて外科への相談を考える。漏出量だけで重症度を決めない。
- 「造影剤投与後の腎機能悪化はすべて造影剤が原因」と断定しない。

# 17. 後処理：3D画像だけを見ない

| 方法 | 何をするか | 得意 | 注意点 |
|---|---|---|---|
| 多断面再構成（MPR） | 体積データを任意断面で切り直す | 解剖、長軸、外傷 | 厚い元画像では階段状アーチファクト・部分容積効果 |
| 曲面多断面再構成（CPR） | 曲がる構造に沿って展開する | 冠動脈、尿管、膵管 | 経路設定に依存し、周囲との位置関係が歪む |
| 最大値投影（MIP） | 一定の厚みの中で最大のボクセル値を投影する | 造影血管、肺結節 | 投影厚、構造の重なり、石灰化、骨で病変を隠す。深さ情報が乏しい |
| 最小値投影（MinIP） | 一定の厚みの中で最小のボクセル値を投影する | 気道、低吸収構造 | 部分容積効果、構造の重なり |
| ボリュームレンダリング（VR） | 不透明度と色を割り当てて体積表示する | 手術説明、全体の位置関係 | 閾値・不透明度で形が変わる。原画像の代替ではない |
| 領域抽出 | 臓器・病変を抽出する | 体積測定、術前計画 | はみ出し・欠損、操作者・モデルへの依存 |
| 仮想単純画像（VNC） | スペクトラルデータからヨード成分を除いて単純CT相当像を推定する | 撮影相を減らせる可能性 | 実測した単純CTを常に代替できず、カルシウム・脂肪・小病変で差が生じ得る |
| ヨードマップ | 物質分離によりボクセル内のヨード濃度・分布を推定する | 造影効果・ヨード分布の可視化／定量、灌流血液量（PBV：ヨード分布に基づく代用指標）の評価 | 単一時相から脳血流量（CBF）を直接測るものではない。体動、位置ずれ、測定可能な濃度範囲に注意 |

原則は、**薄い等方性の元データ＋診断に適した厚さの横断像／MPR**である。MIP、VR、人工知能（AI）による抽出は理解を助ける表示であり、必ず元画像を確認する。

# 18. CT線量と最適化

他の条件が同じなら、X線を多く使うほど画像の粒状感は減るが、患者の線量は増える。線量指標は車の計器に似ており、装置出力や検査全体の規模を比べる目安であって、患者個人の臓器線量そのものではない。容積CT線量指数（CTDIvol）は標準ファントムでの装置出力、線量長積（DLP）はそれに撮影長を加味した値、体格補正線量（SSDE）はさらに患者の大きさを考慮した推定値、と段階的に整理する。

## 18-1. 指標を区別する

加重CT線量指数（CTDIw）は

`CTDIw = (1/3) CTDI100,c + (2/3) CTDI100,p`

`CTDI100,c` は100 mmのペンシル型電離箱で測る標準ファントム中心値、`CTDI100,p` は周辺測定値の平均である。通常、頭部用16 cmと体幹用32 cmのファントムを区別する。

ヘリカル撮影の単純な関係は

`CTDIvol = CTDIw / ピッチ`

逐次撮影では概念的に

`CTDIvol = (N × T / I) × CTDIw`

ここで `I` は隣接する逐次撮影間の寝台移動量である。隙間・重複で値が変わる。

`DLP = CTDIvol × 撮影長`

| 指標 | 表すもの | 表さないもの |
|---|---|---|
| 容積CT線量指数（CTDIvol、mGy） | 標準ファントム条件での装置出力指標 | その患者の臓器吸収線量そのもの |
| 線量長積（DLP、mGy·cm） | 装置出力×撮影長で表す検査全体の規模 | 個人のリスクそのもの |
| 体格補正線量（SSDE、mGy） | `SSDE ≈ f(Dw, CTDIファントム径) × CTDIvol` による、患者体格を考慮した撮影範囲中央部の平均吸収線量の推定 | 変換係数fは水等価径（Dw）と、表示CTDIvolが16 cm／32 cmのどちらのファントム基準かに対応させる。撮影範囲全体の平均、臓器別線量、局所の点線量、将来リスクの確定値ではない |
| 実効線量（mSv） | 組織加重を用いた集団レベルの比較・最適化の概算 | 個人の正確なリスク予測 |
| 診断参考レベル（DRL） | 同種検査の代表的な線量と比較する最適化の目安 | 線量限度や、超えたら即危険という閾値 |

`E ≈ k × DLP` は実効線量の概算に使われ、kの単位は `mSv/(mGy·cm)` である。kは部位、年齢、性別、ファントム・組織加重係数などに依存し、個人のリスクや臓器線量の断定には使わない。

## 18-2. 正当化と最適化

- **正当化**：その検査で得る利益がリスクを上回るかを考える。重複検査、代替検査、妊娠、小児を考慮する。
- **最適化／合理的に達成可能な限り低くする原則（ALARA）**：診断目的を満たす範囲で、合理的に達成可能な限り低い線量とする。最小線量そのものが目標ではなく、低すぎて診断不能でも不適切である。
- **DRLを用いた監査**：撮影手順、患者の体格、CTDIvol、DLP、放射線線量構造化レポート（RDSR）を追跡し、外れ値と画像品質を検討する。

## 18-3. 線量を下げる実務

1. 撮影範囲と相数を絞る。最も確実に総線量へ効く。
2. 患者の体格・診断目的に合わせてkVpとmAを決める。小児は成人用の撮影手順を単純に縮小せず、体格に応じて設定する。
3. 長軸方向・角度方向のAECを適切に使う。位置決め画像の方向、腕の位置、中心ずれはmA変調を誤らせる。
4. IR／DLRを使い、単に雑音を消すのではなく病変検出能を検証する。
5. 心臓CTでは、前向き心電図同期、心電図に応じた管電流変調、高ピッチ撮影、広範囲検出器などから適応に合う方法を選ぶ。
6. ヘリカル撮影のオーバーレンジングには、動的zコリメーションなどを使う。短い撮影範囲ほど相対的な寄与が問題になる。
7. 前面ビスマス遮蔽はAEC、画質、スペクトラル撮影へ干渉し得るため、現代は臓器に応じた管電流変調や撮影手順全体の最適化を優先する。

# 19. 発展的CT技術

## 19-1. 心臓CT

| 方法 | 特徴 | 線量・用途 |
|---|---|---|
| 前向き心電図同期逐次撮影 | 選択した心位相で逐次撮影 | 通常は低線量、冠動脈形態の評価。心拍変動に弱く、機能情報が限定される |
| 後向き心電図同期ヘリカル撮影 | 全心周期をヘリカル収集し、各心位相を再構成 | 心機能・最適位相の評価、通常は高線量。心電図に応じた管電流変調で低減できる |
| 2管球高ピッチ撮影 | 1心拍で高速に広範囲を撮影 | 適切な低心拍・規則的な心拍で、体動アーチファクトと線量を低減できる |
| 広範囲検出器による1心拍撮影 | 心臓全体を1回転で撮影 | 階段状アーチファクトを減らす。検出器幅・回転条件に依存する |

冠動脈CTAでは、時間分解能、空間分解能、体動、石灰化による過大表示（ブルーミング）、ヨード造影の時相が同時に問題になる。低心拍ほど有利な傾向はあるが、固定の心拍数閾値を装置の違いを無視して暗記しない。複数心拍再構成は複数心拍のデータを組み合わせて時間分解能を上げる一方、心拍変動により位置ずれが生じ得る。

## 19-2. 二重エネルギー／スペクトラルCT

2種類以上のエネルギー情報を得る方法には、2管球方式、高速管電圧切替、2層検出器、分割フィルタなどがある。

- **物質分離**：物質ごとに異なるエネルギー依存性を利用し、ヨード、カルシウム、尿酸などを分離する。
- **低keV仮想単色X線画像（VMI）**：ヨードコントラスト↑。ただし雑音・アーチファクト↑のことがある。
- **高keV VMI**：ビームハードニング・金属アーチファクト↓。ただしヨードコントラスト↓。
- **ヨードマップ**：物質分離によりヨード濃度・分布を推定する。単一時相のマップはCBFそのものではない。
- **VNC**：撮影相を減らせる可能性があるが、実測した単純CTを常に置き換えられるわけではない。
- **実効原子番号・電子密度マップ**：物質性状の評価や治療計画に利用する。

過去問の典型は「ヨードを目立たせるなら低keV」「金属・ビームハードニングを減らすなら高keV＋MAR」である。ただし低keV画像の雑音は、再構成法、線量、患者の体格で変わる。

## 19-3. フォトンカウンティングCT

従来のエネルギー積分型検出器が、シンチレータを介して入射X線のエネルギーを積算するのに対し、フォトンカウンティング検出器は半導体でX線を電気信号へ直接変換し、入射光子を個別に数えてエネルギー閾値ごとに分類する。低エネルギー閾値を設定して電子雑音を除きやすく、検出器隔壁を減らして画素を小さくしやすい。期待される利点は、高い空間分解能、エネルギー情報、線量・コントラスト効率の改善である。すでに臨床導入されているが、高い計数率でのパルス重なり、電荷共有、校正、大量のデータ、費用などに課題があり、すべての検査で従来CTを自動的に上回るとは限らない。

## 19-4. CT灌流画像

造影剤の時間濃度曲線から血流動態を推定する。中心容積原理は

時間単位をそろえれば `CBF = CBV / MTT`、すなわち `CBV = CBF × MTT`。臨床表示でCBFをmL/100 g/min、CBVをmL/100 g、MTTを秒とする場合は

`CBF [mL/100 g/min] = 60 × CBV [mL/100 g] / MTT [s]`

動脈入力関数、静脈出力関数、逆畳み込み計算、造影剤到達の遅延・分散、体動、撮影範囲が結果へ影響する。繰り返し撮影のため線量と造影剤量を最適化し、メーカー間で数値を単純比較しない。

## 19-5. CT透視と複合画像装置

- **CT透視**：画像誘導下手技をほぼリアルタイムで支援する。同一断面の反復照射による患者の局所皮膚線量・組織反応と、術者の手指・水晶体被ばくに注意する。低mA、間欠照射、最終画像保持、照射時間の短縮、距離、ガントリ側の遮蔽、針保持具、線量監視を用い、手をX線ビーム内へ入れない。
- **陽電子放出断層撮影（PET）／CT・単一光子放射断層撮影（SPECT）／CT**：CTのHUを、PETでは511 keV、SPECTでは各核種の放出光子エネルギーに対応する線減弱係数マップへ変換し、解剖学的位置合わせと減弱補正に使う。CTが511 keVでの減弱を直接測定するわけではない。散乱補正は放出データやモデルに基づく別処理だが、減弱情報を利用する実装もある。位置合わせ用低線量CTと診断用造影CTを区別する。呼吸・体位ずれ、金属、高濃度造影剤により補正アーチファクトが生じるため、PETでは減弱補正画像だけでなく非補正画像も照合する。

# CT章の最終確認

1. kVpを下げるとヨードコントラストが上がる理由を、K吸収端とX線スペクトルで説明できるか。
2. mAsを4倍にしたとき、量子雑音は何倍になるか。
3. ピッチを上げると線量が必ず下がる、と断言できない理由は何か。
4. CTDIvolと患者吸収線量はなぜ同じではないか。
5. スライスを薄くしたとき、z分解能・雑音・部分容積効果はどう動くか。
6. 高周波強調カーネルは低コントラスト検出能へどんな影響を与え得るか。
7. 頭蓋底のビームハードニングと金属アーチファクトの対策は何か。
8. 低keV VMIと高keV VMIの使い分けは何か。

**確認解答**：1 低kVpでは実効エネルギーがヨードのK吸収端へ近づき、ヨードの相対的なX線減弱が上がる。2 雑音は1/2。3 AECや実効mAs一定の制御により、mAが補償され得る。4 標準ファントムで測る装置出力指標だから。5 z分解能↑、雑音↑、部分容積効果↓。6 雑音増加により低コントラスト検出能を下げ得る。7 適切なX線出力・中心合わせ、薄層収集、MAR、高keV VMIなど。8 低keVはヨード強調、高keVは金属・ビームハードニング低減に使う。

# 22. 未知の画像・撮像法を読む手順

## 22-1. MRI

1. **解剖と断面**：2Dか3Dか、スライスの厚み、歪み、MIPか元画像かを確認する。
2. **水を見る**：CSF・胆汁・尿が明るければT2強調または強いT2強調を考える。CSFだけが抑制されていればFLAIRなどを考える。
3. **脂肪を見る**：脂肪が明るいか、均一に抑制されているかを確認し、STIR、周波数選択法、ディクソン法を考える。
4. **T1と造影**：脂肪、白質・灰白質、造影前後を比較する。造影後だけを見て「もともとT1高信号」と誤認しない。
5. **DWIはADCと対**：DWI高信号＋ADC低値か。b=0画像とT2強調像も確認する。
6. **磁化率**：信号欠損が大きく見えるブルーミング、静脈、鉄が目立つならT2\*/SWIを考える。位相画像と強度画像を区別する。
7. **投影画像は元画像へ戻る**：MRA/MRCPのMIPだけで狭窄・結石を断定しない。
8. **アーチファクトの方向**：位相エンコード方向、読み出し方向、スライス方向のどこに出ているかを確認し、撮像条件と合うかを考える。

## 22-2. CT

1. **単純か造影か**：血管、腎・尿路、実質の増強、基準となる単純像を確認する。
2. **造影時相**：動脈相、門脈相、遅延相のどれかを、目的の血管と臓器の増強から判断する。
3. **表示条件**：脳・軟部・肺・骨のウィンドウを切り替える。1つの表示条件で見えなくても「存在しない」とは限らない。
4. **スライス厚・再構成関数**：薄層で鋭い再構成か、厚いスライスで平滑な再構成かを確認し、肺・骨用と軟部用を区別する。
5. **アーチファクト**：頭蓋底、肩、金属、体動、リング状の乱れを確認し、撮影時に生じたのか再構成で生じたのかを分ける。
6. **スペクトラル画像**：VMIのkeV、ヨードマップ、VNC、MARの有無を確認する。VNCを実測した単純CTと混同しない。
7. **3Dは元画像へ戻る**：MIPのスラブ厚や重なり、VR・領域抽出の閾値や透明度による見え方を確認する。
8. **検査全体の線量**：余分な造影時相・撮影範囲がないかを確認する。1つの撮影系列のCTDIvolだけで総検査線量を判断しない。

# 23. 過去問のひっかけ集

## MRI

- 「180°パルスでT2減衰が回復する」→ **誤り**。静的なB0不均一による可逆的な位相ずれを再収束させる。
- 「GREはT2を反映する」→ GREの横緩和は **T2\*** に従う。ただし画像の強調はTR・TE・フリップ角によりT1、プロトン密度（PD）、T2\*のいずれにもなり得る。
- 「FSEのTEは最初のエコー時間」→ **誤り**。k空間の中央を収集するエコーの時刻が実効TEである。
- 「k空間の中央は空間分解能を決める」→ 中央は主に信号強度とコントラスト、周辺は輪郭と細部に関係する。
- 「k空間は常に中央から埋める」→ **誤り**。データの充填順序による。
- 「マトリックスを増やすとSNRも上がる」→ FOV一定ならボクセルが小さくなり、SNRは低下する。
- 「BWを広げるとSNRが上がる」→ 通常は低下する。一方、化学シフトとEPIの歪みは減る。
- 「STIRはGd造影後の脂肪抑制T1強調像に適する」→ **誤り**。T1が短縮した増強組織まで抑え得る。
- 「DWI高信号なら拡散制限」→ **ADC低値を確認**。T2透過効果（T2シャインスルー）による見かけの高信号がある。
- 「ADCは水分子の移動距離そのもの」→ **誤り**。ADCはb値などの測定条件から求める「見かけの拡散係数」である。
- 「FAが高ければ線維束が実在する」→ **誤り**。トラクトグラフィは計算による推定で、線維が交差する部分に弱い。
- 「TOFでは血流は常に高信号」→ **誤り**。遅い流れ、撮像面内の流れ、飽和、乱流では信号が低下する。
- 「PCでVENCは高いほどよい」→ **誤り**。高すぎると遅い流れへの感度が落ち、低すぎると折り返す。
- 「MREは弾性を直接測る」→ 外部振動で生じたせん断波の変位をMRIで測り、計算から硬さを推定する。
- 「体動ゴーストはすべて位相方向」→ 通常の直交座標型撮像では位相方向が主だが、放射状に収集する撮像などでは見え方が異なる。

## CT

- 「ヨードK吸収端は約80 kVp」→ **誤り**。K吸収端は33.2 keVである。kVpは管電圧で、X線スペクトルの最大エネルギーを決める。
- 「mAsを2倍にすると雑音は1/2」→ **誤り**。`1/√2`。
- 「WWを広げれば雑音が減る」→ **物理的な雑音は不変**。表示上、目立ちにくくなるだけである。
- 「拡大表示で装置の空間分解能が上がる」→ **誤り**。表示を細かく見せるだけで、取得済みの分解能は変わらない。
- 「ピッチを上げればz分解能が必ず上がる」→ **誤り**。z方向のデータ間隔が粗くなり得る。
- 「ピッチを上げれば線量が必ず下がる」→ 1回転あたりのmAsを固定した単純な条件での傾向である。AECや実効mAsの設定では単純に決まらない。
- 「CTDIvolは患者が受けた平均線量」→ **誤り**。標準ファントムで測る装置の出力指標である。
- 「DLPが同じなら個人のリスクも同じ」→ **誤り**。年齢、撮影部位、体格、臓器の放射線感受性が異なる。
- 「鋭い再構成関数はすべての病変検出に優れる」→ **誤り**。雑音が増え、低コントラスト病変を見つけにくくし得る。
- 「高keV VMIはヨードを目立たせる」→ 通常は逆である。低keVはヨードのコントラストを上げ、高keVは金属・ビームハードニングを減らす。
- 「VNCは常に真の単純CTを代替できる」→ **誤り**。
- 「MIPは狭窄評価の最終画像」→ **誤り**。スラブ厚、石灰化・骨、重なり、部分容積効果の影響があるため、元画像やMPRも確認する。

# 24. 数式・関係式 集約表

## MRI

| 項目 | 式 | 読み方 |
|---|---|---|
| ラーモア周波数 | `f0=(γrad/2π)B0` | B0が強いほど周波数が高い。γradは角周波数で表した磁気回転比（単位rad/s/T） |
| フリップ角 | `α=γrad∫B1(t)dt` | RFパルスの強さと持続時間で決まる |
| T1回復 | `Mz=M0[1−exp(−t/T1)]` | 90°パルス後の縦磁化回復を表す簡略式 |
| T2減衰 | `Mxy=Mxy0 exp(−t/T2)` | tがT2と等しいとき横磁化は約37%になる |
| T2\* | `1/T2*=1/T2+1/T2′` | 静的磁場不均一の影響が加わるため、T2*はT2以下になる |
| SE信号 | `S∝ρ[1−e^(−TR/T1)]e^(−TE/T2)` | TRとTEを変えたとき、信号がどちらへ動くかを見る近似式 |
| IRの信号消失 | `TI≈T1 ln2` | 理想的な180°反転後に信号がゼロとなるTI |
| スライス厚 | `Δz=BW_RF/[(γrad/2π)Gslice]` | 傾斜磁場Gを強くするかRF帯域幅を狭くすると薄くなる |
| 画素 | `FOV/マトリックス` | FOV一定ならマトリックスを増やすほど画素が小さくなる |
| 2D FSE撮像時間 | `TA≈TR×Ny×NEX/(ETL×R)×PF` | PFは部分フーリエの実収集率。心電図同期などを使うと別に延長し得る |
| エルンスト角 | `cosαE=e^(−TR/T1)` | 理想条件でSPGR信号が最大となるフリップ角 |
| 化学シフト | `画素のずれ=Δf/（1画素当たりのBW）` | BWを広げると画素のずれが小さくなる |
| 水・脂肪の周波数差 | `Δf≈3.5 ppm×f0` | B0が強いほど周波数差（Hz）が大きい |
| DWI | `b=γrad²G²δ²(Δ−δ/3)` | δは傾斜磁場をかける時間、Δは開始時刻の間隔。b値は通常s/mm² |
| ADC | `S=S0e^(−b×ADC)` | ADCは通常mm²/s。2つのb値では `ln[S(b1)/S(b2)]/(b2−b1)`、b1=0なら信号の対数比をbで割る |
| PC-MRI | `Δφ=γrad×M1×v` | 位相差が速度に比例 |
| 並列撮像のSNR | `SNR_R≈SNR_0/(g√R)` | 加速率Rを上げるほどSNRが低下する |
| SNR概算 | `SNR∝ボクセル体積×√NEX/√BW` | コイルなど他条件を固定したときの増減を見る |

## CT

| 項目 | 式 | 読み方 |
|---|---|---|
| X線減弱 | `I=I0e^(−∫μdl)` | 対数変換して線積分へ直す |
| 投影データ | `p=−ln(I/I0)=∫μdl` | 多方向のpから線減弱係数μを再構成する |
| CT値 | `HU=1000(μ−μ水)/μ水` | 水0、空気約−1000 |
| ピッチ | `1回転当たりの寝台移動距離/総コリメーション` | 他の条件が固定されているか確認する |

| ボクセル体積 | `Δx×Δy×スライス厚` | 部分容積効果と雑音に関係する |
| 量子雑音 | `σ∝1/√mAs` | mAsを4倍にすると雑音は1/2 |
| 線量 | `線量∝mAs` | 他の条件が同じ場合 |
| CTDIw | `(1/3)CTDI100,c+(2/3)CTDI100,p` | 100 mm電離箱で測る標準ファントム内の重み付き指標 |
| CTDIvol | `CTDIw/ピッチ` | ヘリカルCTで用いる単純式 |
| DLP | `CTDIvol×撮影長` | 撮影範囲や相数が増えると大きくなる |
| SSDE | `f(Dw, CTDIファントム径)×CTDIvol` | 患者の水等価径Dwと16/32 cmファントムの違いを補正する |
| 実効線量の概算 | `E≈k×DLP` | 個人のリスクを確定する値には使わない |
| ヨード量 | `濃度×注入量` | 単位はgI |
| IDR | `濃度×注入速度` | 1秒あたりのヨード投与量。単位はgI/s |
| 中心容積原理 | `CBF=CBV/MTT` | 単位をそろえる。MTTが秒、CBFが毎分なら `CBF=60×CBV/MTT` |

| k空間 | 位置と濃淡を再構成する前の生データ領域 |
| シミング | B0の均一性を調整すること |
| SAR | RFによる体内のエネルギー吸収の指標。全身・局所の加熱に関係 |
| VENC | PC-MRIで位相の折り返しなく表せる速度範囲 |
| HU | 水を0、空気を約−1000とするCT値 |
| kVp | X線管電圧。X線の最大エネルギーとスペクトルを左右 |

| ピッチ | 1回転あたりの寝台移動距離を総コリメーションで割った値 |
| 再構成関数（カーネル） | CT再構成の周波数特性。鋭い・平滑など |

| AEC/TCM | 患者のX線減弱に応じて管電流を自動調整する機能 |
| CTDIvol | 標準ファントムに基づくCT装置の出力指標 |
| DLP | CTDIvol×撮影長。検査全体の線量の目安 |
| SSDE | 水等価径DwとCTDIファントム径に応じてCTDIvolを補正した体格別線量推定値。臓器線量そのものではない |
| DRL | 同種検査の線量最適化に使う診断参考レベル。患者ごとの線量上限ではない |
| VMI | スペクトラルCTから作る仮想単色エネルギー画像 |
| MAR | 金属アーチファクト低減法。撮影・再構成・スペクトラル法を含む総称 |

# 30. 最終まとめ

MRIは、`B0でMzを作る → B1で倒す → T1/T2/T2*で戻る → エコーを作る → 傾斜磁場で位置を付ける → k空間を読む`という一本線で理解する。撮像法の名称は、この流れのどこをどう変えたかを表している。

CTは、`X線を通す → 検出器でIを測る → −ln（対数変換）で線積分へ直す → 多方向の投影データからμを再構成する → HUへ変換する → ウィンドウで表示する`という一本線で理解する。撮影条件は、X線光子数、エネルギー、データの細かさ（標本化）、再構成、表示のどの段階を変えるかで整理する。

最後に常に問う：

1. 何を測っているか。
2. どの撮像・撮影条件を変えたか。
3. 信号・コントラスト、分解能、雑音・SNR、時間、アーチファクト、線量・安全はどう動くか。
4. その画像は元データか、再構成画像か、投影・表示画像か。
5. 例外や代償を無視した「必ず」「常に」になっていないか。

この5問に戻れば、未知の選択肢でも原理から判定できる。
